# 金錢服務經營者能力評核 — 模擬試

[English version →](README.md)

香港海關「金錢服務經營者能力評核」的離線模擬試程式。

- 題庫共 **1,594 題**，按各單元官方材料的篇幅比例分佈於 7 個官方單元，每題均
  備有英文及繁體中文版本，並附解釋及所引用官方文件的確切段落。
- 完全仿照真實試卷：35 題、限時 75 分鐘、採用真實的及格準則。
- **一個檔案，毋須安裝。** 整個程式就是一個 HTML 檔案，用 Google Chrome 開啟即可。
  毋須上網、毋須執行任何程式、毋須帳戶。應考紀錄只儲存於你自己的瀏覽器。

## 快速開始

1. **下載 `mso-ca.html`**：在 [Releases 頁面](../../releases/latest)下載（約 3 MB，
   題庫及字型已內嵌在檔案內）。
2. **用 Google Chrome 開啟**：直接雙擊檔案；如你的預設瀏覽器並非 Chrome，請按右鍵 →
   開啟方式 → Google Chrome。Microsoft Edge 及 Firefox 亦可使用。
3. **選擇試卷語言**（英文或繁體中文），然後開始。

請把檔案放在固定位置（例如「文件」資料夾），每次開啟同一個檔案。

## 使用說明

**模擬試。** 按「開始模擬試」會從題庫隨機抽出 35 題——每個單元 5 題，並按單元
次序排列，與真實試卷相同——同時開始 75 分鐘倒數。作答方式：點擊選項、按鍵盤
`A`–`E` 或 `1`–`5`（再按一次可清除），或直接在題目旁的答題紙上點選圓圈。
大部分題目設四個選項，組合題則設五個。
`Enter` 或 `→` 前往下一題，`←` 返回上一題；點擊答題紙上的題號可跳至任何一題。
「標記」可標示需要再看的題目。「交卷」前會先列出未作答的題目；「離開」會儲存
進度並返回主頁，但計時不會暫停——與真實試場一樣——你可隨時從主頁繼續。時間
用完會自動交卷。計時器在剩餘 10 分鐘時轉為琥珀色，5 分鐘時轉為紅色。

**及格準則。** 必須**同時**符合兩項才算及格：**每個**單元錯題不多於 2 題，
**及**全卷總分達 25/35 或以上。即使總分 32/35，只要任何一個單元錯 3 題即屬不及格。
成績頁會以一行圓點顯示每個單元的成績並標示底線，一眼便看出哪個單元超出上限。

**成績及重溫。** 交卷後會顯示合格／不合格、分數、各單元成績，以及全卷每題的
重溫：你的答案、正確答案、解釋及出處。切換至「只看錯題」可只顯示錯誤的題目；
「練習答錯的題目」會針對這些題目作練習。

**練習。** 選擇一個或多個單元，不設時限地練習：每題作答後即時顯示對錯，連同
解釋及出處。全部題目看過一遍後會重新開始一輪。

**進度。** 累積了應考紀錄後，主頁會顯示每次應考的分數、各單元的累計答對率
（低於 60% 以紅色顯示，即有機會超出每單元錯 2 題的上限），以及最常答錯的題目
——點擊可查看答案，或按「練習這些題目」。

**過往紀錄。** 每次應考都會儲存於此瀏覽器，並可在「過往紀錄」表中重溫。
「儲存紀錄至檔案 (.md)」會把所有紀錄寫成一份可閱讀的 Markdown 檔案（各單元答對率、
最常答錯的題目及其答案、每次應考的每一題錯題），程式亦可透過「從檔案載入紀錄」
把它讀回——可作備份，或轉移至另一部電腦使用。「清除紀錄」會在確認後刪除全部紀錄。

**語言及主題。** 頂欄可隨時（包括考試途中）在 **EN**、**中文** 及 **EN+中**
（同時顯示兩種語言）之間切換，亦可選擇「自動／淺色／深色」主題。

**快速練習。** 在 Chrome 網址列的 `mso-ca.html` 後加上 `?minutes=20`，即可以自訂
時限進行模擬試。

## 題庫

**共 1,594 題**，全部只根據官方材料撰寫。每題設一個正確答案、中英雙語解釋，
以及可對照原文核實的出處；大部分題目設四個選項，下文所述的組合題則設五個。

各單元題數刻意不等。各單元背後的官方材料篇幅相差可達八倍——第 5 單元只有約
3,500 字，第 2、4、6 單元則有數以萬字計——故每個單元的題數按其材料篇幅而定。
如此每一題均可追溯至真實條文，而非改寫鄰題。

### 真實試卷的模樣

海關公布過八道參考試題：七道載於通函 MSSB/CA_01/2021（`docs/TC/19`），一道載於
《能力評核須知》第 7.1 段。八道全部屬**組合題**——題幹、四或五項編號陳述，以及
五個指明陳述組合的固定選項：

> 金錢服務經營者進行機構層面的洗錢／恐怖分子資金籌集風險評估時，應顧及下列哪種因素？
>
> 1. 金錢服務經營者的目標市場及客戶類別
> 2. 金錢服務經營者業務的盈利能力
> 3. 金錢服務經營者業務的性質、規模、多元程度及複雜程度
> 4. 金錢服務經營者的交付渠道
>
> a) 1、2 及 3　b) 1、2 及 4　c) 2、3 及 4　d) 1、3 及 4　e) 以上皆是

真正要做的，是找出不正確的一項陳述——此處為第 2 項——再選出列出其餘三項的選項。
故題庫亦收錄此類題目，選項一字不改地照用官方印本，字母固定且不會隨機排列——
1,594 題之中共 **109 題**，每個單元 15 至 19 題，故每份模擬試卷會抽到兩三題。

題庫其餘部分沿用一般的四選項形式：該形式每次只考一項條文，較適合逐點學習；
組合題則是試場上真正的模樣。

須留意參考試題早於 2023 年 6 月的《指引》、2022 年《打擊洗錢條例》修訂及 2026 年
5 月的收費調整，故其用語只作對照，不會直接照抄。

題庫為 `web/questions.json` 檔案。如需新增或修改題目，編輯該檔案後重新產生 HTML
檔案即可（見下文）；`go test ./...` 會檢查題庫格式（上表所列各單元題數、每題
4 個選項、中英文及出處齊備），並會標示同一單元內意思過於相近的題目。

另有六項檢查，針對格式看不出來的問題。選項次序於抽題時隨機排列，位置不會洩露
答案，但長度會：2026 年 9 月的審核發現，85% 題目的正確選項是四者中最長的一個，
單憑「揀最長」便足以通過 71% 的模擬試卷。現時測試將此比例限制在每單元 45% 以
內，並要求每個出處註明段號或條號而非只列文件名稱，以及規定繁體中文須沿用官方
中文本的用語——每個定義概念使用法定譯名，英文寫 ML/TF 之處，中文必須「洗錢／
恐怖分子資金籌集」兩者兼備。

修正這項缺失時，發現了問題的另一半，並已加入第五項檢查。當初把答案縮短、讓最
長的選項變成錯誤答案，只是把破綻搬了家：全題庫約一半題目的答案變成第二長，而
「揀第二長」與「揀最長」同樣容易學會。因此測試改為檢查整體分布——中英文皆然，
答案位於四個長度位次中任何一個位次的比例，均不得超過 40%。撰寫題目時的實用原
則是：長短要有變化。答案有時最長、有時最短，而各選項之間的長度差距應只有數
字之譜，不應相差整整一個子句。

最後兩項檢查源自 2026 年 9 月的第二次審核。其一禁止解釋以位置稱呼選項（「選項二」、
"option 2"）：選項於抽題時隨機排列，這樣的說法只會指向該次抽題碰巧排在該位置的
選項；該次審核共發現 37 處。其二規定組合題的選項須與官方印本逐字相同，並限制答案
落在任何單一字母的比例——哪個字母正確，取決於出題者把哪一項陳述寫成錯的；若那總是
第二項陳述，其可學會的程度與長度破綻並無二致。

**29 份官方文件的中英文原本**已收錄於 [`docs/`](docs/README.zh-Hant.md)，程式內
每一個出處均可對照原文核實。其中 16 份為通函，於 2026 年 9 月補存：《能力評核須知》
第 6.1 段列出評核的五類參考資料，第 (5) 項為「海關向金錢服務經營者發出的通函」，
故通函屬考試範圍，而此前只存了 2026 年的三份。

## 紀錄儲存位置

所有應考紀錄、進行中的模擬試及你的設定，均儲存於你自己電腦上瀏覽器的本機儲存空間
（local storage）。資料不會傳送至任何地方——檔案內沒有任何網絡程式碼。實際而言：
紀錄在關閉瀏覽器、重新啟動電腦或更換新版 HTML 檔案後仍會保留；紀錄屬於一部電腦上的
一個瀏覽器，因此兩人各用自己的電腦時，紀錄自然各自分開；清除該瀏覽器的網站資料
則會刪除紀錄。Chrome 有一點須注意：所有本機 HTML 檔案共用同一份儲存空間，如你亦會
開啟其他本機 HTML 頁面，請以「儲存紀錄至檔案」作為可靠的紀錄。

## 從原始碼重新產生檔案

程式庫內存放程式的各個部分（`web/`）及一個小型 Go 程式，負責把它們合併成單一檔案。
只需 Go 1.21 或以上，別無其他要求。

```bash
go test ./...                          # 題庫完整性檢查及 vet
go run . -export-html dist/mso-ca.html # 產生單一 HTML 檔案
go run .                               # 或：開發時在本機提供 web/ 內容
```

執行 `build.cmd`（Windows）或 `./build.sh`（Mac／Linux）亦會產生 `dist/mso-ca.html`。

字型：內嵌 DM Sans 及 DM Mono（SIL Open Font License，見 `web/fonts/`）；
中文字採用作業系統的字型。

## 發布新版本

新版本以標籤（tag）發布。推送以 `v` 開頭的標籤即會執行
[`.github/workflows/release.yml`](.github/workflows/release.yml)：先對題庫執行
vet 及測試，再由該次提交的原始碼建立單一檔案，並附於新的 GitHub release，
連同自動產生的說明。

```bash
git tag v1.2.0
git push origin v1.2.0
```

測試在建立檔案之前執行，因此未能通過題庫檢查的標籤不會成為可供下載的版本。
`dist/` 已列入 gitignore：該檔案從不提交至程式庫，只在標籤發布時由原始碼建立。
