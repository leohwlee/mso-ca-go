# 金錢服務經營者能力評核 — 模擬試

[English version →](README.md)

香港海關「金錢服務經營者能力評核」的離線模擬試程式。

- 題庫共 **140 題**，7 個官方單元每個 20 題，每題均備有英文及繁體中文版本，
  並附解釋及所引用官方文件的確切段落。
- 完全仿照真實試卷：35 題、限時 75 分鐘、採用真實的及格準則。
- Windows 及 Mac 均只需一個小程式。毋須上網、毋須安裝、毋須帳戶。
  應考紀錄只儲存於你自己的電腦。

## 快速開始

1. **下載**：在 [Releases 頁面](../../releases/latest)下載適合你電腦的檔案：
   `mso-ca-windows-amd64.exe`（Windows）、
   `mso-ca-macos-arm64`（Apple Silicon 晶片的 Mac）或
   `mso-ca-macos-amd64`（Intel 晶片的 Mac）。
2. **執行**：Windows 直接雙擊 `.exe`。Mac 請先在該資料夾開啟「終端機」執行一次
   `chmod +x mso-ca-macos-arm64`，然後雙擊檔案（首次須按右鍵 → 打開，因程式未經
   Apple 公證）。程式會開啟一個小型終端機視窗，並在瀏覽器打開
   <http://127.0.0.1:8321>。**練習期間請保持該終端機視窗開啟**；完成後關閉視窗
   （或按 `Ctrl+C`）即可。
3. **選擇試卷語言**（英文或繁體中文），然後開始。

可選參數：`-port 9000` 改用其他連接埠；`-no-browser` 不自動開啟瀏覽器。

**免安裝方式：單一 HTML 檔案。** 同一個 Release 亦提供 `mso-ca.html`，即整個程式
合併成一個檔案（約 400 KB，已內嵌題庫及字型）。下載後以 **Google Chrome** 開啟——
直接雙擊，或按右鍵 → 開啟方式 → Google Chrome（如你的預設瀏覽器並非 Chrome）。
毋須執行任何程式、沒有終端機視窗，在 Mac 上亦不會遇到「無法識別的開發者」提示。
Edge 及 Firefox 同樣可用。應考紀錄照樣由瀏覽器保存；唯一分別是 Chrome 會把所有
本機 HTML 檔案的紀錄放在同一處，如你會開啟多個本機 HTML 頁面，請以「儲存紀錄至檔案」
作為可靠備份。（隨時可用 `mso-ca -export-html mso-ca.html` 重新產生此檔案。）

## 使用說明

**模擬試。** 按「開始模擬試」會從題庫隨機抽出 35 題——每個單元 5 題，並按單元
次序排列，與真實試卷相同——同時開始 75 分鐘倒數。作答方式：點擊選項、按鍵盤
`A`–`D` 或 `1`–`4`（再按一次可清除），或直接在題目旁的答題紙上點選圓圈。
`Enter` 或 `→` 前往下一題，`←` 返回上一題；點擊答題紙上的題號可跳至任何一題。
「標記」可標示需要再看的題目。「交卷」前會先列出未作答的題目；「離開」會儲存
進度並返回主頁，但計時不會暫停——與真實試場一樣——你可隨時從主頁繼續。時間
用完會自動交卷。計時器在剩餘 10 分鐘時轉為琥珀色，5 分鐘時轉為紅色。

**及格準則。** 必須**同時**符合兩項才算及格：**每個**單元錯題不多於 2 題，
**及**全卷總分達 25/35 或以上。即使總分 32/35，只要任何一個單元錯 3 題即屬不及格。
成績頁會以一行圓點顯示每個單元的成績並標示底線，一眼便看出哪個單元超出上限。

**成績及重溫。** 交卷後會顯示合格／不合格、分數、各單元成績，以及全卷每題的
重溫：你的答案、正確答案、解釋及出處。切換至「只看錯題」可只顯示錯誤的題目；
「練習答錯的題目」會針對這些題目作練習。

**練習。** 選擇一個或多個單元，不設時限地練習：每題作答後即時顯示對錯，連同
解釋及出處。全部題目看過一遍後會重新開始一輪。

**進度。** 累積了應考紀錄後，主頁會顯示每次應考的分數、各單元的累計答對率
（低於 60% 以紅色顯示，即有機會超出每單元錯 2 題的上限），以及最常答錯的題目
——點擊可查看答案，或按「練習這些題目」。

**過往紀錄。** 每次應考都會儲存於此瀏覽器，並可在「過往紀錄」表中重溫。
「儲存紀錄至檔案 (.md)」會把所有紀錄寫成一份可閱讀的 Markdown 檔案（各單元答對率、
最常答錯的題目及其答案、每次應考的每一題錯題），程式亦可透過「從檔案載入紀錄」
把它讀回——可作備份，或轉移至另一部電腦使用。「清除紀錄」會在確認後刪除全部紀錄。

**語言及主題。** 頂欄可隨時（包括考試途中）在 **EN**、**中文** 及 **EN+中**
（同時顯示兩種語言）之間切換，亦可選擇「自動／淺色／深色」主題。

**快速練習。** 開啟 `http://127.0.0.1:8321/?minutes=20` 可以自訂時限進行模擬試。

## 紀錄儲存位置

所有應考紀錄、進行中的模擬試及你的設定，均儲存於你自己電腦上瀏覽器的本機儲存空間
（local storage）。資料不會傳送至任何地方；程式本身只是一個本機檔案伺服器。
實際而言：紀錄在關閉程式、重新啟動電腦或更新程式後仍會保留；紀錄屬於一部電腦上的
一個瀏覽器，因此兩人各用自己的電腦時，紀錄自然各自分開；清除該瀏覽器的網站資料
則會刪除紀錄。請使用「儲存紀錄至檔案」作備份。

## 從原始碼建置

只需 Go 1.21 或以上，別無其他要求：伺服器只使用標準程式庫，前端為純 HTML、CSS
及 JavaScript，無需建置步驟。

```bash
go test ./...             # 題庫完整性檢查及 vet
go build -o mso-ca.exe .  # 單一執行檔，內嵌所有內容
```

執行 `build.cmd`（Windows）或 `./build.sh`（Mac／Linux）可一次過交叉編譯三個
平台的執行檔至 `dist/`。

字型：內置 DM Sans 及 DM Mono（SIL Open Font License，見 `web/fonts/`）；
中文字採用作業系統的字型。
