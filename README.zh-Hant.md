# 金錢服務經營者能力評核 — 模擬試

[English version →](README.md)

香港海關「金錢服務經營者能力評核」的練習程式——持牌人的獨資經營者、合夥人或
董事必須通過的那個考試。

程式就是**一個 HTML 檔案**。下載後用 Chrome 開啟，之後永遠離線可用。毋須安裝、
毋須帳戶、毋須上網。成績只留在你自己的瀏覽器。

- **1,594 題**，全部根據官方文件撰寫，每題均註明所依據的確切段落。
- 全部備有中英雙語——英文、繁體中文，或兩者並列。
- 完全仿照真實試卷：35 題、7 個單元、限時 75 分鐘、採用真實的及格準則。

## 快速開始

1. **下載 `mso-ca.html`**：在 [Releases 頁面](../../releases/latest)下載
   （約 3.5 MB，題目及字型已內嵌在檔案內）。
2. **用 Google Chrome 開啟**：直接雙擊；或按右鍵 → 開啟方式 → Google Chrome。
   Microsoft Edge 及 Firefox 亦可。
3. **選擇試卷語言**，然後開始。

請把檔案放在固定位置（例如「文件」資料夾），每次開啟同一個檔案——你的應考紀錄
就存在那裡。

## 如何用它備試

由零開始到應考當日，建議這樣用。

**1 · 逐個單元學習。** 開啟「練習」，只勾選一個單元，不設時限做下去。每答一題
即時顯示正確答案、解釋，以及所依據的段落。四選項題目的價值就在這裡：每題只考
一項條文，答錯時你立刻知道自己未掌握哪一條規則。建議一次只做一個單元，不要
七個一起做。

**2 · 先看清自己的真實水平。** 做一份完整模擬試，不要暫停計時——真實試場也不會
停。交卷後，成績頁會以一行圓點顯示每個單元的成績並標示及格底線，哪個單元弱一眼
就看得出。

**3 · 集中攻弱項。** 「練習答錯的題目」會針對你做錯的題目重做。主頁亦會統計你
在所有試卷中最常做錯的題目——點擊任何一題即可看答案及解釋。

**4 · 實戰演練。** 在模擬試那張卡上勾選**「試場模式」**。35 題會全部抽自海關
實際採用的**組合題**格式（見下文）。建議臨近應考才用：這是程式最接近真實試卷的
狀態。

**5 · 盯住底線，不是總分。** 必須**同時**符合兩項才算及格：**每個單元錯題不多於
2 題**，**及**總分達 **25/35** 或以上。即使總分 32/35，只要任何一個單元錯 3 題
即屬不及格。大部分不及格的人，都是輸在某一個單元——所以第 3 步比死谷總分重要。

應考紀錄會留在瀏覽器，可以看到自己有沒有進步。「儲存紀錄至檔案」會產生一份可讀
的 Markdown 紀錄，可作備份、帶到另一部電腦，再載入回程式。

## 題庫內容

**共 1,594 題**，全部只根據官方材料撰寫。每題設一個正確答案、中英雙語解釋，以及
可對照 [`docs/`](docs/README.zh-Hant.md) 內原文核實的出處。

各單元題數刻意不等，因為各單元背後的官方材料篇幅相差可達八倍。每個單元的題數

### 兩種題型

**四選項單選題。** 佔題庫大部分。每題只考一項條文，最適合逐條規則學習。程式每次
抽題時都會重新排列選項次序，所以位置絕不會洩露答案。

**組合題。** 題幹、四或五項編號陳述，以及五個指明陳述組合的固定選項：

> 金錢服務經營者進行機構層面的洗錢／恐怖分子資金籌集風險評估時，應顧及下列哪種因素？
>
> 1. 金錢服務經營者的目標市場及客戶類別
> 2. 金錢服務經營者業務的盈利能力
> 3. 金錢服務經營者業務的性質、規模、多元程度及複雜程度
> 4. 金錢服務經營者的交付渠道
>
> a) 1、2 及 3　b) 1、2 及 4　c) 2、3 及 4　d) 1、3 及 4　e) 以上皆是

真正要做的，是找出不正確的一項陳述——此處為第 2 項，因為盈利能力並非洗錢／恐怖
分子資金籌集的風險因素——再選出列出其餘三項的選項。

**這正是海關採用的格式。** 海關歷來公布的參考試題全部屬此類：通函 MSSB/CA_01/2021
的七道，以及《能力評核須知》第 7.1 段的一道。因此題庫的選項一字不改地照用官方
印本，而且不會隨機排列——在這種題型中，次序本身就是題目的一部分。勾選
**「試場模式」**，整份模擬試就會全部抽自這類題目。

### 官方文件

**29 份**官方文件的中英文原本已全部收錄於 [`docs/`](docs/README.zh-Hant.md)，
程式內每一個出處均可對照原文核實。這些正是《能力評核須知》第 6.1 段列出的五類
參考資料：條例、《打擊洗錢及恐怖分子資金籌集指引》、《牌照指引》、海關其他指引，

其中 `docs/TC/19` 特別值得一看——那是海關歷來唯一公布的參考試題。

## 程式的其他功能

- **答題紙。** 每題旁邊都有一張仿機讀答題紙；可直接在圓圈上作答，或點擊題號跳題。
  已標記的題目也會在該處顯示。
- **鍵盤。** `A`–`E` 或 `1`–`5` 作答（再按一次可清除），`Enter` 或 `→` 下一題，
  `←` 上一題。
- **離開與繼續。** 離開試卷會儲存進度，但計時不會暫停——與真實試場一樣。可從主頁
  繼續作答。
- **語言與主題。** 可隨時切換 EN、中文或雙語顯示（即使考試途中亦可）；並可選
  自動／淺色／深色。
- **自訂時限。** 在網址列的 `mso-ca.html` 後加上 `?minutes=20`，即可做短時間練習。
- **紀錄。** 每份試卷都可重溫；「清除紀錄」會在確認後刪除全部紀錄。

## 應考紀錄存放在哪裡

存放在你自己電腦上、你自己瀏覽器的本機儲存空間。所有資料不會傳送到任何地方——
檔案內並無任何網絡程式碼。關閉瀏覽器、重新開機、甚至換上新版本的 HTML 檔案，
紀錄都會保留。紀錄屬於一部電腦上的一個瀏覽器，所以兩個人各用自己的電腦，紀錄
互不相干；清除該瀏覽器的網站資料則會一併刪除。

有一點關於 Chrome：Chrome 會把所有本機 HTML 檔案的資料存放在同一處，所以如果你
還會開啟其他本機網頁，請以「儲存紀錄至檔案」作為可靠的紀錄。

## 給開發者

本專案存放程式的組成部分（`web/`）及一個小型 Go 程式，用以把它們合併成單一檔案。
只需 Go 1.21 或以上，別無其他依賴。

```bash
go test ./...                          # 題庫檢查 + vet
go run . -export-html dist/mso-ca.html # 產生單一檔案
go run .                               # 或：開發時在本機提供 web/
```

`build.cmd`（Windows）或 `./build.sh`（Mac/Linux）效果相同。

題庫為 `web/questions.json`。`go test ./...` 並非只檢查格式，而是防範一些會悄悄
毀掉題庫的問題——每一項檢查都是在審核中真的發現了該問題之後才加入的。

| 檢查項目 | 防範甚麼 |
|---|---|
| 各單元題數、4 或 5 個選項、中英文齊備、出處齊備 | 題目遺失或只寫了一半 |
| 選項長度平衡及長度位次 | 「一律揀最長」——這招曾經足以通過 64% 的模擬試卷 |
| 出處須有定位 | 只列文件名稱，讀者無從翻查 |
| 法定中文用語 | 使用官方中文本從未採用的字眼 |
| ML/TF 對應 | 中文漏掉「恐怖分子資金籌集」那一半 |
| 不得以位置稱呼選項 | 解釋寫「選項二」，但選項是隨機排列的 |
| 不得有重複題幹，不同單元不得有相同答案 | 同一條問題被問兩次 |
| 組合題格式 | 選項須與官方印本逐字相同，答案字母須分布平均 |

上表背後的做法——如何依據一組固定文件編寫雙語題庫、如何蒙著答案覆核、以及如何量度
那些讓考生不必讀懂教材也能猜中的表面線索——已整理成一份可重用的 skill，見
[`.claude/skills/exam-question-bank/SKILL.md`](.claude/skills/exam-question-bank/SKILL.md)。
它並不限於本考試。

字型：DM Sans 及 DM Mono 以 SIL Open Font License 內嵌；中文使用作業系統字型。

**發佈**以標籤觸發。推送以 `v` 開頭的標籤，會執行
[`release.yml`](.github/workflows/release.yml)：先 vet 及測試題庫，再從該
commit 產生檔案並附加到 GitHub release。測試在產生檔案之前執行，所以未通過檢查
的標籤不會變成可供下載的版本。

```bash
git tag v1.5.0
git push origin v1.5.0
```
